      what this is
      
    
      A local AI for your shell. It runs a model on your own machine by
      default, with no account or telemetry.
      
    
      Your words go to the model's server. It runs on this machine, or on
      another machine of yours (spark client URL).
      
    
      An ordinary user's token opens only that user's chat and store. The
      admin token can run commands here; with passwordless sudo, it can
      run as root.
      
    
      Anyone on your network can read plain HTTP, including tokens.
      
    
      Every button on this page is a spark verb run on the machine, and the
      page never runs a command you did not click. The theme at the top changes
      this browser only.
      
    
      API health:  (no token needed; everything
      else under /api/ takes your token as a cookie or bearer).
