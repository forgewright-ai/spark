      what this is
      
    
      Your box's own AI, in the browser. Chat is yours alone -- your
      messages live in a sealed store only your token opens. What this
      page can do is what your shell can do: every button is a
      spark verb run on the box, and the page never runs a
      command you did not click.
      
    
      The palette under settings changes this browser only; the theme
      picker (admin) runs spark theme on the box itself.
      
    
      API health:  (no token needed; everything
      else under /api/ takes your token as a cookie or bearer).
