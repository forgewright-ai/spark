# Ideas

This document is not tied to a spark release. It is kept up to date
as spark changes.

Ideas for later. None is a promise. An idea that is picked moves to
`docs/ROADMAP.md`.

## Open

- Answers from the machine's own numbers. `? why is it slow today`
  reads what `spark check` and `spark stats` keep, and answers.
- A forecast from the same numbers, such as when the disk will fill.

## Parked

- The shared engine as a system service. `spark serve share` covers
  the need for now.
- A prompt-line benchmark: about 40 questions per OS, each with a
  checker. The model list could then rank on quality, not size alone.
- `spark token`: which keys this machine holds, and whether the server
  accepts each. Names only, never a value.
