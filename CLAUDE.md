# spark -- what a session loads

@AGENTS.md

`docs/REFERENCE.md` is the full reference, 3,100 lines. It does not
load by itself. Read the section named here before touching its topic,
and nothing more of it.

- A principle, a word, or what leaves the machine: "Principles".
- Any change: "The four obligations", then the bullet of "Adding
  things" that fits. There is one for a doc, a package, a config file,
  the landing rule, a check row and a chaos scenario. There is one for a
  prose data file, a route, a shell thing, a grounded contract and a
  spark app. The last three are the client shape, your own llama-server
  and a shared engine, then a model.
- Where a file lives, or a runtime path under the config, state and
  data directories: "Layout".
- An interface between parts: "Contracts", by number. 1 is
  bootstrap.sh and 2 install.sh. 3 is the KEY=value files and every
  key. 4 is spark line and spark do: the prompt line, the widgets, the
  sandbox. 5 is spark brain --porcelain. 6 is the widgets' marker and
  the look file. 7 is spark check. 8 is signing: help, refusals,
  errors. 9 is the page's HTTP API and its route table. 10 is spark
  edit, 11 spark read, 12 spark ask, 13 spark drill, 14 spark watch,
  15 spark do --porcelain, and 16 spark mcp and spark steps.
- A verb, a switch, a confirm, a progress frame, an exit code: "The
  grammar".
- A proof before a claim: "Verifying a claim" and "Host-dependent test
  fixtures".
- A release, a tag, a key: "Releasing". A person tags a major. A patch
  is the lane in AGENTS.md, "The patch lane".
- A thread or a file read into a request: "Context read limits".

`tests/docs_test.py` holds this file under 200 lines and every section
it names to the reference.
